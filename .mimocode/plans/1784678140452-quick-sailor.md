# Plano: Alinhar PoseStudio com funcionalidades VNCCS

## Objetivo
Atualizar o componente `PoseStudio.tsx` para usar as mesmas funcionalidades do node VNCCS `pose_generator.py`, incluindo nomenclatura de joints, renderização OpenPose, e estrutura de dados compatível.

## Análise das Diferenças

### 1. Nomenclatura de Joints (CRÍTICO)
| Atual (PoseStudio) | VNCCS |
|---------------------|-------|
| `right_shoulder` | `r_shoulder` |
| `right_elbow` | `r_elbow` |
| `right_wrist` | `r_wrist` |
| `left_shoulder` | `l_shoulder` |
| `left_elbow` | `l_elbow` |
| `left_wrist` | `l_wrist` |
| `right_hip` | `r_hip` |
| `right_knee` | `r_knee` |
| `right_ankle` | `r_ankle` |
| `left_hip` | `l_hip` |
| `left_knee` | `l_knee` |
| `left_ankle` | `l_ankle` |
| `right_eye` | `r_eye` |
| `left_eye` | `l_eye` |
| `right_ear` | `r_ear` |
| `left_ear` | `l_ear` |
| `mouth_left` | (não existe no VNCCS) |
| `mouth_right` | (não existe no VNCCS) |

### 2. Posições Default do Skeleton
VNCCS usa coordenadas diferentes e mais precisas para o esqueleto 512x1536.

### 3. Estrutura de Dados
- VNCCS: `{ canvas: {width, height}, poses: [{joint: [x,y], ...}, ...] }` (12 poses)
- PoseStudio: `{ canvas: {width, height}, poses: [{ joints: {joint: [x,y]} }] }` (1 pose)

### 4. Renderização
- VNCCS: OpenPose padrão (cores por osso) via Python/OpenCV
- PoseStudio: Canvas 2D com cores simples

## Fase 6: Corrigir Backend (workflow.ts)
**Arquivo:** `src/main/workflow.ts`

O `workflow.ts` **NÃO injeta o `poseData`** no node `VNCCS_PoseGenerator`. O parâmetro é logado mas não é passado para o workflow do ComfyUI.

Adicionar após o loop principal em `buildPrompt()`:
```typescript
// Injetar dados de pose no VNCCS_PoseGenerator
if (params.poseData) {
  const poseNode = nodes.find(n => n.type === 'VNCCS_PoseGenerator')
  if (poseNode) {
    const poseEntry = prompt[String(poseNode.id)]
    if (poseEntry) {
      const inputs = poseEntry.inputs as Record<string, unknown>
      inputs['pose_data'] = params.poseData
      inputs['line_thickness'] = (params as any).lineThickness ?? 3
      inputs['safe_zone'] = (params as any).safeZone ?? 100
    }
  }
}
```

Também adicionar `lineThickness` e `safeZone` ao tipo `GenerationParams` em `src/shared/types.ts`.
